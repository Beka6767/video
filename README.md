# Git және GitHub оқу жобасы

Бұл жоба — **Git** пен *GitHub* жұмысын үйрену үшін жасалған.

## Жобаның мақсаты

- Репозиторий құру
- Тармақтармен (branch) жұмыс істеу
- Тармақтарды біріктіру (merge)
- Қайшылықты (conflict) қолмен шешу

## Негізгі командалар

1. `git init` — репозиторий құру
2. `git add .` — файлдарды индекске қосу
3. `git commit -m "хабарлама"` — өзгерісті сақтау

---

### Тармақтармен жұмыс

```bash
git branch
git checkout -b dev
git checkout main
git merge --no-ff dev
```

> Тармақ — негізгі кодты бұзбай тәжірибе жасауға арналған көшірме.

### Командалар кестесі

| Команда | Мағынасы |
|---|---|
| `git branch` | тармақтар тізімі |
| `git checkout -b аты` | тармақ құру және оған ауысу |
| `git merge аты` | тармақты біріктіру |
